「Webコンテンツ作成」の成果

本テーマについて

このテーマでは、Webページを作成するための基本的な知識を学ぶ。HTMLやCSS、JavaScriptの基本的な構文を理解し、Webページを作成するためのスキルを身につけることが目標である。 またJavaScriptの中のDOMやイベント処理を学ぶことで検索結果を表示するWebページや数当てゲームを作成することができるようになることも目標である。

プロジェクト課題について

プロジェクト課題では、グルメ情報を検索するWebページを作成した。ユーザーがキーワードを入力して検索ボタンを押すと、外部からグルメ情報を取得し、検索結果を表示することができる。 検索結果には店舗名や住所、営業時間、最寄駅などの情報が表示される。また、検索結果が複数ある場合は、検索に引っかかったものを全て表示し、それぞれの店舗情報をリスト形式で表示するようにした。 またCSSには食欲が湧くような色を中心に使用し、見やすいページになるように工夫した。

プロジェクト課題で作成したページ: project.html

数当てゲーム

この数当てゲームはコンピュータが乱数を使って1~10までの数字を答えとして決め、答えとなった数字をユーザが3回以内に当てるゲームである。 画面には数字を入力するテキストボックスと回答を判定するためのボタンが置かれている。回答ボタンを押すと下に判定結果が表示される。入力した数字と答えが違う場合は、答えが入力された数字より 大きいか小さいかのヒントを表示する。3回以内に当てることができた場合、ユーザの勝利となる。当たられなかった場合はユーザの敗北となって答えが表示される。すでに正答している場合や4回目以降、 答えても同じ文字列が表示される。もう一度やりたい場合はページを再読み込みするとできる。

数当てゲームのページ: kazuate.html

各授業回の学習事項

第１回 WWW と HTML

HTMLの要素にはブロック要素とインライン要素があり、インライン要素の中にブロック要素は配置できない。また要素に追加する情報として属性を設定でき、 属性を設定する=の後には"をつけなければならない。HTMLには特殊文字があり<や'を表すには別の記述が必要になる。

演習の成果: 演習1-4: HTMLのさまざまな要素

第２回 CSS による Web ページの装飾

CSSには、HTMLで書いた文を装飾する役割がある。特定の要素の色を変えたり、背景を変えるにはそれに合ったセレクタやプロパティ名を指定しなければならない。 また属性を追加することによってその属性だけの装飾をすることができるようになる。文字を見やすくするには影をつけることが重要である。

演習の成果: 演習2-3

第３回 JavaScript の基本

JavaScriptでは、titleの下にscript要素でJavaScriptファイルを読み込ませることで動きのあるページにすることができる。その際、defer属性を必ず指定しなければならない。 jsファイル側で出力するには、console.log()を使用する。javaとjavascriptの構文は別のものなので注意する。javascriptでは、エラーの場所が分からないためfirefoxの開発者ツールを利用すると エラーの場所を知ることができる。

演習の成果: 演習3-6

第４回 DOM と JavaScript

HTMLの中の要素を書き換えるのは、DOMという操作を使う。DOMとJavaScriptを組み合わせることで、ページの内容を動きのあるものにすることができる。input要素のtype属性に指定する文字列によって様々な ユーザーインターフェースを作ることができる。ユーザーインターフェースはブラウザによって表示が異なるため注意する。

演習の成果: 演習4-10

第５回 イベント処理

要素を新規作成するときには、createElement()を使用する。内部に要素を配置するには、要素.insertAdjacentElement()を使う。画像を追加したい場合は、src属性と属性の値をsetAttribute()で追加する。 要素を削除したいときは、remove()を使用する。li要素を追加する時に注意すべきこととして、ul要素を作成してからli要素を作成ことと要素を追加するたびにcreateElement()を宣言しなければならない。

演習の成果: 演習5-7

第６回 通信処理

通常ブラウザでは、リンクをクリックしたり、再読み込みしたりする際、サーバとの通信が行われる。この通信をAjax通信で行った。プロジェクト課題では、axiosというライブラリを使用して通信を行いデータを取得するようにした。 Ajaxを利用するには、htmlのhead要素の中にスクリプト要素でaxiosと繋がるようにする必要がある。そしてgetやthenなどを使用することで通信を行えるようになる。
